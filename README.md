# CodSoft Artificial Intelligence Internship 🚀

This repository contains all the completed tasks for the **Artificial Intelligence Internship** at **CodSoft**. The projects cover foundational AI concepts ranging from Natural Language Processing (NLP) to Game Theory, Recommendation Engines, and Computer Vision.

---

## 📁 Repository Contents

### 1. Task 1: Chatbot with Rule-Based Responses
* **File:** `Task1_Chatbot.ipynb`
* **Description:** An interactive conversational assistant built using regular expressions and rule-based pattern matching. It answers common queries including greetings, date/time, explanations of AI and Python concepts, and general chat.
* **Tech Stack:** Python, `re`, `datetime`.

---

### 2. Task 2: Tic-Tac-Toe AI (Minimax Algorithm)
* **File:** `Task2_TicTacToe_AI.ipynb`
* **Description:** An unbeatable AI agent that plays classic Tic-Tac-Toe against a human opponent. It utilizes the **Minimax Algorithm** to simulate all possible future game states and always choose the optimal move.
* **Tech Stack:** Python, Game Theory, Minimax Search Algorithm.

---

### 3. Task 4: Movie Recommendation System
* **File:** `Task4_Recommendation_System.ipynb`
* **Description:** A content-based movie recommendation engine. It processes movie genres and plot descriptions using **TF-IDF Vectorization** and computes **Cosine Similarity** to suggest the most relevant movies based on user preferences.
* **Tech Stack:** Python, `pandas`, `scikit-learn` (`TfidfVectorizer`, `cosine_similarity`).

---

### 4. Task 5: Face Detection & Recognition
* **File:** `Task5_Face_Detection.ipynb`
* **Description:** A Computer Vision application that automatically detects human faces in images using OpenCV's pre-trained **Haar Feature-based Cascade Classifiers** and visualizes bounding boxes around detected regions.
* **Tech Stack:** Python, `opencv-python` (`cv2`), `matplotlib`.
